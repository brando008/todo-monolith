# Todo Monolith

A full-stack todo application with a Go backend and Vue 3 frontend.

## Structure

```
├── main.go          # Go backend entry point
├── frontend/        # Vue 3 frontend
└── go.mod           # Go module
```

## Backend

Go backend using pgx for PostgreSQL.

```bash
go run main.go
```

## Frontend

Vue 3 + TypeScript + Vite + UnoCSS

```bash
cd frontend
npm install
npm run dev
```
